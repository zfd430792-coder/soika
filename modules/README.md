# Модули для `.ml`

Сюда складываются модули, которые можно поставить одной командой:

```
.ml id
.ml notes
```

Команда `.ml имя` скачивает `modules/имя.py` из этого репозитория и устанавливает его.
Ссылку на каталог можно поменять в настройках: `.cfg` → **Загрузчик** → `repo`.

Поставить модуль из любого другого места:

```
.dlmod https://example.com/module.py
```

или отправить `.py` файл в чат и ответить на него `.loadmod`.

## Что здесь есть

| Модуль | Команды | Зачем |
|---|---|---|
| `info.py` | `.info`, `.ping` | версия, аптайм, память, задержка до Telegram |
| `eval.py` | `.e` | выполнить Python-код прямо из чата |
| `terminal.py` | `.shell`, `.killshell` | команды системы с живым выводом |
| `security.py` | `.sudo`, `.support`, `.owner`, `.security` | кому и какие команды разрешены |
| `id.py` | `.id` | ID чата, сообщения и пользователя |
| `notes.py` | `.note`, `.notes`, `.delnote`, `.clearnotes` | короткие заметки в базе юзербота |

Эти модули не встроены специально: Сойка работает и без них, а лишние команды
только мешают. Поставил — они появились в `.help`, выгрузил `.unloadmod` — исчезли.

## Как добавить свой

Модуль — это один `.py` файл с классом-наследником `loader.Module`.
Шаблон и описание API — в [README проекта](../README.md#как-написать-модуль).
