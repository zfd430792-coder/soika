# Каталог модулей для `.ml`

Всё, что нужно для работы, у Сойки **встроено** — после входа в аккаунт сразу
доступны `.info`, `.ping`, `.e`, `.shell`, `.sudo`, `.id`, `.note` и остальные
команды. Ставить что-то дополнительно не нужно.

Этот каталог — место для **необязательных** модулей. Файл `modules/имя.py`
отсюда ставится одной командой:

```
.ml имя
```

Ссылку на каталог можно поменять в настройках — `.cfg` → **Загрузчик** → `repo`,
чтобы `.ml` брал модули из твоего репозитория.

Поставить модуль из любого другого места:

```
.dlmod https://example.com/module.py
```

или отправить `.py` файл в чат и ответить на него `.loadmod`.

## Как добавить свой

Модуль — это один `.py` файл с классом-наследником `loader.Module`.
Шаблон и описание API — в [README проекта](../README.md#как-написать-модуль).
Положи файл сюда — и он станет доступен по `.ml имя`.
